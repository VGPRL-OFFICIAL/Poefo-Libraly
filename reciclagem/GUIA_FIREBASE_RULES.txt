POR QUE OCORRE O ERRO?
═══════════════════════════════════════════════════════════════════

O Firebase Realtime Database tem "Regras de Segurança" que controlam 
quem pode ler e escrever dados. O erro PERMISSION_DENIED significa que 
as regras estão BLOQUEANDO a operação.

É como uma fechadura - sem a chave correta, você não consegue abrir.


O QUE FAZER?
═══════════════════════════════════════════════════════════════════

┌─ PASSO 1: Abrir Firebase Console ─────────────────────────────┐
│                                                                 │
│ 1. Acesse: https://console.firebase.google.com                │
│ 2. Clique em "captu-libraly" (seu projeto)                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─ PASSO 2: Ir para Realtime Database ─────────────────────────┐
│                                                                 │
│ 1. Menu esquerdo: "Realtime Database"                         │
│ 2. Clique em "Rules"                                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─ PASSO 3: Trocar as Regras ───────────────────────────────────┐
│                                                                 │
│ Copie e cole EXATAMENTE isto:                                 │
│                                                                 │
│ {                                                              │
│   "rules": {                                                  │
│     ".read": true,                                            │
│     ".write": true                                            │
│   }                                                            │
│ }                                                              │
│                                                                 │
│ (Depois fazemos regras mais seguras)                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─ PASSO 4: Publicar ───────────────────────────────────────────┐
│                                                                 │
│ 1. Clique em "Publish"                                        │
│ 2. Confirme se pedido                                         │
│ 3. Aguarde 2-3 minutos para aplicar                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─ PASSO 5: Testar ─────────────────────────────────────────────┐
│                                                                 │
│ 1. Volte para o chat                                          │
│ 2. Pressione F5 (refresh) para recarregar                     │
│ 3. Tente enviar uma mensagem                                  │
│                                                                 │
│ Se funcionar: ✓ Pronto!                                       │
│ Se não: Abra o console (F12) e procure por erros             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘


SE AINDA NÃO FUNCIONAR
═══════════════════════════════════════════════════════════════════

1. Abra o console do navegador: Pressione F12
2. Clique na aba "Console"
3. Procure por mensagens de erro
4. Envie uma mensagem de teste
5. Verifique se aparece:
   
   Procure por: "=== DEBUG: Enviando Mensagem ===" 
   
6. Se vir o erro, copie e compartilhe comigo

VERIFICAR COM CONSOLE DO NAVEGADOR
═══════════════════════════════════════════════════════════════════

Para ver o que está acontecendo:

1. Abra o chat em: http://localhost:5000/html/chat.html
2. Pressione F12 (abre developer tools)
3. Clique em "Console"
4. Tente enviar uma mensagem
5. Você verá logs como:

   "=== DEBUG: Enviando Mensagem ===" 
   ConvId: direct_uid1_uid2
   UserId: uid1
   ✓ Mensagem enviada com sucesso

   OU

   "✗ ERRO ao enviar mensagem:"
   Código de erro: PERMISSION_DENIED


SE MUDOU AS REGRAS E AINDA DÁ ERRO
═══════════════════════════════════════════════════════════════════

1. Aguarde 5 minutos (às vezes demora para sincronizar)
2. Tente novamente
3. Se persistir, talvez o problema seja:
   - A regra não foi publicada corretamente
   - Há cache do navegador (limpe com Ctrl+Shift+Del)
   - O Firebase precisa ser reiniciado
